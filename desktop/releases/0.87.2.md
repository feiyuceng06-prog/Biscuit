# Biscuit 0.87.2

## 更新

- 桌面外观统一为浅色、深色、跟随系统，移除旧皮肤及装饰资源。
- 新用户默认跟随系统；手动选择会被记住，系统外观变化也会同步到已打开的终端。
- 旧浅色皮肤迁移到浅色，盗梦空间皮肤迁移到深色，保留原有配置和聊天记录。
- 启动页删除「Biscuit帮助您工作」文案，只保留图标描边与填充动画；支持 Esc 跳过和系统减少动态效果设置。

## 下载与安装

- Windows x64：下载 `Biscuit.Setup.0.87.2.exe`，双击安装，内含 Git Bash。
- Ubuntu / Debian x64：下载 deb 后运行 `sudo apt install ./feiyu-desktop_0.87.2_amd64.deb`。
- Linux x64 AppImage：运行 `chmod +x Biscuit-0.87.2.AppImage` 后打开。需要 FUSE；也可使用 README 中的一键安装命令。

安装包未签名，macOS 暂无安装包。模型配置和已有会话沿用原目录，命令仍为 `feiyu` 和 `feiyu-desktop`。可用附件 `SHA256SUMS` 校验下载文件。

自动发布须通过 Python 回归、Linux/Windows 桌面及打包验证、Windows 安装升级和原生状态回归。模型交互测试使用合成数据与本地模拟服务，不代表真实模型服务测试。Windows 不提供 Linux bubblewrap 沙箱。

## English

Desktop appearance now offers Light, Dark, and Follow System. Preferences persist, system changes update an open terminal, and legacy skins migrate by brightness. The startup screen keeps only the animated Biscuit icon, with Escape and reduced-motion support.

Existing commands, settings, and conversations are retained. Windows x64 and Linux x64 packages are unsigned; SHA256SUMS is included. No macOS package is provided. Release gates use synthetic data and local provider fixtures, not live model requests.
