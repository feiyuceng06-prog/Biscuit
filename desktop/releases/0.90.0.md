# Biscuit 0.90.0

在「设置 → 模型」点击「列出模型」，选中模型后，Biscuit 会读取接口提供的上下文容量、单轮输出上限和图像输入能力。接口只返回 ID 时，可保留默认值或手动配置。手动填写的上限优先。

In model settings, list and select a model to fill in provider-reported context capacity, output limit and image input support. Manual values take priority. ID-only catalogs can still use defaults.
