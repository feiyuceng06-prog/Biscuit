# Biscuit 0.88.0

## 更新

- 启动后自动检查 GitHub 正式发布版本，运行期间每 6 小时再次检查。
- 有适用的新版本时，侧栏底部显示版本号，提供「查看更新」与「稍后」；「检查更新」支持手动检查。
- 「稍后」会记住当前忽略的版本；手动检查仍可再次查看，后续新版本仍会提醒。
- 离线或检查失败不会打断聊天；手动检查会显示失败提示，并允许稍后重试。
- 仅提示正式版本及已上传完整的适用安装包，保留浅色、深色与跟随系统外观。

## 下载与升级

- Windows x64：下载 `Biscuit.Setup.0.88.0.exe` 并安装。
- Ubuntu / Debian x64：下载 deb 后运行 `sudo apt install ./feiyu-desktop_0.88.0_amd64.deb`。
- Linux x64 AppImage：运行 `chmod +x Biscuit-0.88.0.AppImage` 后打开；下载新文件不会自动替换旧文件及快捷方式。

0.87.2 及更早版本尚无更新检查功能，需要先手动升级一次。更新提示打开 GitHub 发布页，不自动下载或覆盖正在运行的应用。配置和聊天记录继续使用原目录。可用附件 `SHA256SUMS` 校验下载文件。

安装包未签名，macOS 暂无安装包。发布检查覆盖 Python 回归、Linux/Windows 桌面与打包、Windows 安装升级及原生状态回归。更新检查测试使用合成发布信息，不依赖公网响应。

## English

Biscuit now checks stable GitHub releases at startup and every six hours. A sidebar notice shows a compatible new version with a release-page link and dismissal, alongside a manual check button. Dismissal persists for that version; manual checks can reveal it again, and future versions still notify. Offline checks do not interrupt chat. Only complete uploaded packages trigger a notice.

Versions 0.87.2 and earlier require one manual upgrade to gain this feature. Updates open the release page; they do not automatically download or replace the running application. Downloading a new AppImage does not replace the old file or shortcut. Existing settings and conversations are retained. Windows x64 and Linux x64 packages are unsigned; SHA256SUMS is included. No macOS package is provided.
