# Biscuit 0.96.0

- 在「办公 → 新建演示文稿」导入已有 PPTX 的文字、表格、图表数据和演讲备注。对话中的 Agent 也可以按页读取 PPTX，并报告缺失或损坏的内容部件。
- 在「设计方案」中选择受众、使用场景、品牌色、字体或参考文稿。逐页规划支持商业汇报、流程、时间线、原生图表和会前阅读。可复制页面并撤销，导出的文字、照片和图表保留为独立可编辑对象。
- 摄影集支持多图导入、排序、图注及裁切焦点。摄影导出会实际渲染并检查版面，发现溢出或裁切时尝试局部调整；仍有阻断问题时保留草稿并列出原因。
- 实际渲染检查需要本机可用的 LibreOffice 和 Poppler。一般文稿可通过环境变量 `presentation_design_engine=1` 启用自动设计与导出预检。Windows 和 Linux 安装包可从本页下载，SHA256SUMS 提供文件校验值。
