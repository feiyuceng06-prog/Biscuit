# Biscuit 0.89.0

桌面聊天输入框新增「思考强度」。拖动陨石、点档位，或用方向键选择日常、标准、深入和 Pro。越接近 Pro，陨石旋转越快，流星越密；抵达 Pro 时会出现气流和一次短震。开启系统的减少动态效果选项后，可静态操作。

四档分别请求 `low`、`medium`、`high` 和 `xhigh`，从下一条消息起作用，支持范围由当前模型接口决定。「恢复模型设置」可还原已配置的强度和思考开关。

## English

The desktop composer now has four reasoning levels with a meteorite slider. Choose a level by dragging, clicking, or using the arrow keys. The next message uses the selected effort on the current model. Support varies by provider. Reset restores the configured effort and thinking setting. The control follows the desktop theme and respects reduced motion.
