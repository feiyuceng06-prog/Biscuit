# Windows command environment

The Windows installer contains the unmodified PortableGit 2.56.1 distribution
from Git for Windows, including Bash, Git, MSYS2 and other tools. It preserves
upstream copyright and license files. These components have their own licenses,
including GNU GPL licenses; Feiyu's MIT license does not replace them.

- Upstream release and source: https://github.com/git-for-windows/git/releases/tag/v2.56.1.windows.1
- Git for Windows build environment and component sources: https://github.com/git-for-windows/build-extra
- Git for Windows license and component information: https://gitforwindows.org/faq.html
- Distribution SHA-256: `9dd04a608ceb5f6ab32a73709e0ecb159d211da71b697c45ff81f6dd0c6b49c7`

The bundled distribution is updated when Feiyu is updated. It does not modify
the system PATH. Windows 10 or newer on x64 is required by this Git release.
