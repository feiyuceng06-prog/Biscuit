# 修复原生图表的可编辑零值

打开最初的分析新版 PPTX 后，第 3 页的图表缓存和截图均有数字 0，嵌入工作表的 B3 却为空。PptxGenJS 4 写工作表时把数值 0 当成空值。过去的断言搜索整个 XML，命中了共享字符串索引。现在导出器向该库的数值 XML 序列化传入零的字面表示，回归测试核对每个具体 B 列数据单元格。

用同一固定输入重新导出。第 3 页的 B2:B5 读为 −3、0、2、−1，零所在单元格具有数值类型。原文件 B3 为无值的 v 节点。四张重渲染 PNG 的 SHA-256 均与原始报告一致。新文件的本地预检完成，本次单独运行的远端模型未返回结果。可按相同 PNG 哈希核对原报告的逐页反馈。
